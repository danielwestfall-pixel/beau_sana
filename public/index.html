How to connect
  1. Sign into your own Asana account.
  2. Open the Asana developer console (opens in a new tab) and create a personal access token named BeauSana.
  3. Paste the token above and choose Connect to Asana.

Treat the token like a password. It grants your Asana account's access. Actions you submit here update Asana. If remembered, the token is encrypted by Windows and stored in your local user profile.

If your organization blocks tokens, your Asana administrator will need to allow one or arrange an OAuth connection.
